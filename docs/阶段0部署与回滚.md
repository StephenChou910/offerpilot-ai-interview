# 阶段 0 部署与回滚说明

## 启动前检查

1. 设置 `ENVIRONMENT` 为 `development`、`test`、`staging` 或 `production`。
2. staging/production 设置 `STRICT_CONFIG=true`，并配置非默认数据库、对象存储、JWT 和 AI 密钥。
3. 启动 PostgreSQL、Redis、MinIO 后访问 `/api/health/config`。
4. 确认配置状态为 `OK` 后再启动 Worker。

## 回滚

- 应用代码回滚到上一版本后，保留数据库迁移，不删除已有数据。
- 若迁移 `009_async_task_executions` 尚未被业务使用，可执行对应 Alembic downgrade；生产环境优先采用向前修复，不直接回滚表结构。
- Redis Stream 消费异常时停止 Worker，保留 pending 和 dead-letter 消息，修复后重新启动。

## 备份

- 每日备份 PostgreSQL 数据库和 MinIO 对象存储元数据。
- 备份文件不得提交到代码仓库，恢复演练至少在 staging 执行一次。
